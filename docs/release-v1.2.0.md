# MijiaDeck 定制版 v1.2.0

基于上游 v1.1.2 的定制分支，重点修复摄像头功能的实际问题。

## 摄像头

- **画质真正可切换**：新增「全分辨率」档（`videoquality=3`）。此前全链路把画质限制在 0–2，新机型因此长期停在 640×360。切换画质改为整段重连，摄像头会重新协商码流；若摄像头拒绝该档位，界面会明确提示而不是静默回退。
- **双摄机型可切镜头**：`isa.camera.hlmax` 等「云台 + 枪机」机型，预览窗口内可切换看哪一路。写入 MIoT 属性后会回读校验，属性不生效时联动中继的 `channel` 参数作为第二机制。
- **声音可以开了**：多数摄像头忽略运行中码流上的音频开关，改为停流后以 `enableaudio=1` 重新建流。若摄像头只推 Opus 或确实无音频，会给出提示，不再一直静音。
- **九宫格摄像头墙**：主界面右上角九宫格入口。每格独立会话，最多同时 3 路出画面，其余排队并显示进度，避免一次拉起 9 路导致整体卡死。双击任意一格放大。
- 中继 JVM 参数收紧，单路内存占用明显下降。

## 设备卡片

- **设备详情面板**：点击任意设备卡片即可打开。按设备 MIoT 规格自动生成控件——布尔量做开关、枚举做下拉、带范围的数值做步进器，另附可执行动作与设备信息（型号、固件、在线状态）。摄像头窗口和托盘菜单也有入口。
- **拖拽排序**：卡片可拖动调整顺序，顺序持久化保存；右键菜单对所有设备可用。

## 其他

- 应用内「检查更新」改为指向本仓库，不会再把你导回上游原版覆盖定制功能。
- 版本号 1.2.0，与上游 1.1.x 区分。

## 下载与安装

下载 **MijiaDeck-v1.2.0-windows-x64.zip**（见下方 Assets），完整解压后运行 `MijiaDeck.exe`，无需安装 Python 或 Java。

- 必须完整解压，不能单独移动 EXE；`_internal` 是必需的运行组件。
- 升级：先从托盘菜单退出旧版，再完整解压覆盖原目录，保留 `_internal`。
- 系统要求：Windows 10 1903+ / Windows 11 x64。不支持 Win7 / Win8。
- 登录：用米家 APP 扫码。配置在 `%LOCALAPPDATA%\MijiaDeck`，凭据在用户目录 `.config\mijia-api`。
- 校验：同目录提供 `.sha256`，可执行 `certutil -hashfile MijiaDeck-v1.2.0-windows-x64.zip SHA256` 比对。
